HDREZKA Premium for Lampa — версия 1.0

ЧТО ЭТО
--------
Это отдельный плагин. Online Mod для HDRezka больше не используется.

Схема:
Lampa -> ваш небольшой backend -> библиотека HDRezka -> ваш аккаунт HDRezka.

Backend:
- сам входит в HDRezka;
- использует browser/TLS impersonation;
- ищет фильм;
- не выбирает случайный фильм при плохом совпадении;
- получает озвучки;
- получает сезоны/серии;
- получает видеопотоки и субтитры.

ВАЖНО ПЕРЕД УСТАНОВКОЙ
----------------------
1. Удалите из Lampa ВСЕ старые наши плагины:
   workers.dev/plugin.js?v=...
   rezka bridge v1/v2/v3/v4 и т.д.

2. Полностью перезапустите Lampa.

3. Online Mod можно оставить для Filmix и других источников.
   Наш новый HDREZKA Premium от него не зависит.

РАЗВЁРТЫВАНИЕ НА RENDER
------------------------
Самый простой вариант:

1. Создайте НОВЫЙ репозиторий на GitHub, например:
   hdrezka-premium-lampa

2. Загрузите в корень репозитория эти файлы:
   app.py
   plugin.js
   requirements.txt
   Dockerfile
   render.yaml

3. Откройте Render:
   Dashboard -> New -> Web Service.

4. Подключите GitHub и выберите созданный репозиторий.

5. Render увидит Dockerfile.
   Build/Start команды вручную вводить не нужно.

6. Нажмите Deploy.

7. После запуска Render даст адрес примерно:
   https://hdrezka-premium-lampa.onrender.com

8. Проверьте:
   https://ВАШ-АДРЕС.onrender.com/health

   Должно вернуть:
   {"ok":true,"version":"1.0.0"}

9. В Lampa:
   Настройки -> Расширения -> Добавить плагин

   Вставьте:
   https://ВАШ-АДРЕС.onrender.com/plugin.js?v=1

10. Полностью перезапустите Lampa.

НАСТРОЙКА В LAMPA
-----------------
Откройте:
Настройки -> HDREZKA Premium

Введите:
- логин/e-mail HDRezka
- пароль HDRezka

Отдельную кнопку "Войти" нажимать не нужно.
При первом открытии фильма плагин сам войдёт в аккаунт.

КАК ПОЛЬЗОВАТЬСЯ
----------------
1. Откройте карточку фильма/сериала.
2. Появится кнопка HDREZKA.
3. Нажмите её.
4. Плагин найдёт этот фильм именно на HDRezka.

Если совпадение точное:
- откроется сразу.

Если совпадение сомнительное:
- появится список найденных вариантов;
- выберите нужный вручную.
Это специально сделано, чтобы больше не открывались случайные фильмы.

В фильтре будут:
- Балансер: HDREZKA Premium
- Озвучка
- Сезон (для сериалов)

Для сериала после смены озвучки список сезонов/серий загружается заново,
потому что у HDRezka набор серий может зависеть от перевода.

При запуске видео плагин передаёт в стандартный плеер Lampa:
- поток;
- список качеств;
- субтитры.

БЕЗОПАСНОСТЬ
------------
Логин и пароль хранятся локально в Lampa.
Backend получает пароль только во время входа.

После входа Lampa хранит подписанную сессию с cookies HDRezka.
Backend не хранит аккаунт в базе данных.

Для дополнительной защиты в Render можно добавить Environment Variable:

SESSION_SECRET = любая длинная случайная строка

Например 40-60 случайных символов.

Если SESSION_SECRET поменять, старая сессия в Lampa станет недействительной,
и плагин автоматически войдёт заново при следующем открытии.

ЕСЛИ НЕ РАБОТАЕТ
----------------
Нужен только конкретный текст ошибки с экрана HDREZKA Premium
или лог Render (Logs).

Не нужно снова менять Cloudflare Worker:
этот проект Cloudflare Worker вообще не использует.
