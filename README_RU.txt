ОБНОВЛЕНИЕ С РАБОЧЕЙ 1.1:
1. В GitHub замените:
   - app.py
   - plugin.js
   - Dockerfile
   Старый sitecustomize.py можно удалить, но если оставить — Dockerfile его больше не копирует, поэтому он не влияет.

2. requirements.txt можно заменить на файл из этого пакета (он совместим с текущим).

3. Render сам выполнит Deploy.

4. После Deploy откройте:
   https://hdrezka-premium-lampa.onrender.com/health

   Должно быть:
   version: 2.0.0
   author: DENYS

5. В Lampa лучше сменить URL плагина с ?v=1 на:
   https://hdrezka-premium-lampa.onrender.com/plugin.js?v=20

6. Полностью перезапустить Lampa.

НОВОЕ В v3.0 — НОРМАЛЬНОЕ ПРОДОЛЖЕНИЕ ПРОСМОТРА
------------------------------------------------
- Нативный Lampa.Timeline для каждого фильма и каждой серии.
- Сохраняется точный таймкод (секунда), длительность и процент.
- После выхода из плеера и повторного открытия — продолжение с того же места.
- На серии/фильме отображается стандартная полоска прогресса Lampa.
- В списке видно процент и таймкод.
- После ~92% серия считается просмотренной.
- Для сериалов «Продолжить» автоматически переносится на следующую серию.
- Фильм/сериал добавляется в нативную историю Lampa.
- Работает вместе с DENYS EDITION: озвучка, сезон и качество продолжают запоминаться.

ВАЖНО:
Прогресс хранится в самой Lampa на устройстве через Lampa.Timeline.
Если полностью очистить данные/хранилище Lampa, локальный прогресс тоже очистится.


HDREZKA PREMIUM • DENYS EDITION v3.0
====================================

ГЛАВНОЕ ИСПРАВЛЕНИЕ: РЕАЛЬНЫЙ ТАЙМКОД
--------------------------------------
В v3 таймкод больше НЕ зависит от того, вызовет ли конкретная сборка Lampa
Timeline.handler. Плагин сам находит реальный HTML5 <video> плеера и читает
video.currentTime / video.duration каждые ~2 секунды.

Сохраняется:
- точная секунда просмотра;
- длительность;
- процент;
- фильм / сезон / серия;
- выбранная озвучка;
- время последнего обновления.

Сохранение происходит:
- во время просмотра;
- на паузе;
- при перемотке;
- при завершении;
- при закрытии плеера.

При следующем запуске плагин САМ выставляет video.currentTime.
Это дополнительный механизм поверх стандартного Lampa Timeline, поэтому
resume работает даже если конкретная сборка Lampa игнорирует player.position.

ПАРАЛЛЕЛЬНО ОБНОВЛЯЕТСЯ НАТИВНЫЙ LAMPA TIMELINE
-----------------------------------------------
- полоска прогресса;
- процент и таймкод;
- история Lampa;
- отметка просмотренного;
- восстановление позиции.

НАСТРОЙКИ v3
-------------
- качество по умолчанию;

СКОРОСТЬ
--------
Backend v3 оставляет проверенную схему rezka-ua.tv, но добавляет короткий
session-scoped cache карточек, сезонов/серий и потоков. Данные разных аккаунтов
не смешиваются.
