- /api/about и расширенный /health;
- старый sitecustomize.py больше не нужен.

ОБНОВЛЕНИЕ С РАБОЧЕЙ 1.1:
1. В GitHub замените:
   - app.py
   - plugin.js
   - Dockerfile
   Старый sitecustomize.py можно удалить, но если оставить — Dockerfile его больше не копирует, поэтому он не влияет.

2. requirements.txt можно заменить на файл из этого пакета (он совместим с текущим).

3. Render сам выполнит Deploy.

4. После Deploy откройте:
   https://hdrezka-premium-lampa.onrender.com/health

   Должно быть:
   version: 2.0.0
   author: DENYS

5. В Lampa лучше сменить URL плагина с ?v=1 на:
   https://hdrezka-premium-lampa.onrender.com/plugin.js?v=20

6. Полностью перезапустить Lampa.

ВАЖНО:
- логин/пароль и существующие Storage-ключи сохранены, поэтому настройки аккаунта не должны пропасть;
- рабочий поиск/авторизация из v1.1 не переписаны на другую архитектуру;
- бесплатный Render всё ещё может засыпать; плагин теперь показывает это и повторяет временно упавшие запросы.

Настройки:
Настройки -> HDREZKA Premium • by DENYS

- логин;
- пароль;
- качество по умолчанию;
