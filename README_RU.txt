HDREZKA Premium • DENYS EDITION v4.0 PRO
========================================

ЭТОТ РЕЛИЗ ПЕРЕДЕЛЫВАЕТ ДВЕ КЛЮЧЕВЫЕ ВЕЩИ:
таймкод и сериальный плейлист.

ПОЧЕМУ НЕ РАБОТАЛО РАНЬШЕ
-------------------------
1. Lampa могла открывать HDRezka через внешний/системный плеер.
   Внешний плеер не управляется внутренними Lampa.Timeline и Lampa.Playlist.
   Поэтому таймкод мог не сохраняться, NEXT/PREV и autoplay могли отсутствовать.

2. В v3 плагин реально передавал в Player плейлист из одного элемента:
   [first]. Следующей серии там просто не было.

ЧТО СДЕЛАНО В v4
----------------
- По умолчанию HDRezka принудительно использует ВСТРОЕННЫЙ плеер Lampa.
- Общая настройка плеера пользователя не ломается:
  настройки временно меняются только на время HDRezka и возвращаются после выхода.
- Таймкод теперь отдаётся НАТИВНОМУ Lampa Timeline.
- Используются стандартные хеши Lampa для фильма/серии.
- Native resume: точная позиция, процент, длительность.
- Режимы: автоматически продолжать / спрашивать / всегда с начала.
- Настройка HDRezka работает даже если в общей Lampa стоит другой режим таймкода.
- Настоящий плейлист сериала: все серии всех сезонов выбранной озвучки.
- NEXT / PREV внутри плеера.
- Автоматическая следующая серия.
- Переход с последней серии сезона на первую серию следующего сезона.
- Lazy loading: поток серии запрашивается только когда он реально нужен.
- Prefetch следующей серии для быстрого NEXT.
- Нативная полоска прогресса и отметка просмотрено.
- Фокус сразу на серии "Продолжить".
- Запоминание озвучки.
- Запоминание сезона.
- Выбор качества MAX / 2160 / 1080 / 720 / 480.
- История Lampa.
- Backend cache.
- DENYS EDITION branding.

  Да

  Да

УСТАНОВКА
---------
1. Распаковать архив.
2. Все файлы загрузить в корень GitHub-репозитория с заменой.
3. Commit.
4. Дождаться Render -> Live.
5. В Lampa использовать:

https://hdrezka-premium-lampa.onrender.com/plugin.js?v=40

6. Полностью перезапустить Lampa.

ПРОВЕРКА ТАЙМКОДА
-----------------
Открыть фильм или серию -> посмотреть/перемотать примерно на 5 минут ->
обычно выйти кнопкой Back из встроенного Lampa Player ->
снова открыть ту же серию.

При режиме "Автоматически продолжать" встроенный Lampa Player
должен перейти на сохранённое место.

ВАЖНО
-----
Если выбрать "Как в общих настройках Lampa", то внешний Android/VLC/другой
плеер снова может не поддерживать нативный Lampa playlist/timecode.
Для полного функционала DENYS EDITION оставлять "Встроенный Lampa".
